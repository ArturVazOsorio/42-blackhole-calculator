# 🚀 42 Blackhole Calculator

Uma calculadora simples e precisa para estudantes da 42 estimarem suas datas limites de Blackhole com base na matriz de **Milestone e Pace**.

## 📌 Funcionalidades
- **Cálculo Real de Absorção:** Baseado no limite máximo do **Pace 24**.
- **Aviso de Reajuste de Pace:** Mostra a data exata em que o estudante transiciona para o próximo Pace se não concluir a Milestone a tempo.
- **Suporte a Freezes e Bônus:** Permite adicionar dias extras de congelamento ou conquistas de eventos.
